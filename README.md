A tiny browser game — Asteroid Dodge — built by an AI agent from a single prompt, plus the short video about building it. The entry program copies POST.json, the address of the X post carrying the video, to /output. The game itself lives in game/index.html: fly the rocket with arrow keys or WASD, dodge the asteroids, grab the stars, three hits and the run ends.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
